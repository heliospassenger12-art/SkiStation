# SkiStation 3.25 — Glaciers structurés 360°

Base directe : 3.24.

## Ajouts
- grands champs glaciaires ouest/est dans la haute montagne ;
- langues glaciaires secondaires orientées selon le relief ;
- ruptures/gradins très doux pour suggérer les séracs sans murs infranchissables ;
- lignes d’écoulement discrètes ;
- moraines et bordures rocheuses latérales ;
- tablette glaciaire arrière pour préserver le vrai 360° ;
- cœur des glaciers volontairement large et doux pour permettre de longues pistes accessibles ;
- aucune piste prédessinée.
