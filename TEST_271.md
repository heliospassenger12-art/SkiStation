# SkiStation 2.71 — Visiteurs, finition hiver

Base : 2.70.

## Ajouts visuels
- gants visibles, parfois contrastés ;
- bonnet + pompon sur une partie des visiteurs ;
- col de veste ;
- fixations de ski ;
- spatules avant relevées/accentuées pour mieux lire les skis à distance.

Tous ces objets sont décoratifs et leurs colliders sont supprimés. Aucune IA, route, décision, remontée ou logique de ski n’a été modifiée.

## Test Unity
Vérifier plusieurs visiteurs au front de neige et pendant leur boucle. Confirmer qu’aucune erreur rouge n’apparaît et que les accessoires ne gênent pas la lecture des personnages.

Compilation/Play Mode Unity non exécutés dans l’environnement de génération.
