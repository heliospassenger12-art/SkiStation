# Pure Nature 2 et forêts d’Orcières

Ce kit cible la copie Unity **SkiStation Alpine Empires Avant Première**, version modifiée de l’audit du 20 novembre 2026, sous Unity 6000.3.7f1 et URP 17.3.0.

1. Recopier le contenu de `Payload` dans le projet Unity Avant Première.
2. Importer localement **Pure Nature 2: Mountains** de BK avec sa configuration URP.
3. Dans Unity, exécuter **SkiStation → Visuals → ValAlpin → Installer le rendu en jeu** pour générer les références locales.
4. Pour le relief aléatoire, ouvrir **SkiStation → Terrain → Pure Nature 2 → Relief aléatoire**.

Le kit contient les scripts SkiStation. L’archive commerciale et les catalogues générés localement restent dans l’installation Unity.

## Validation sur la copie Avant Première

- Orcières sous `SkiStation_URP`. Les versants boisés utilisent les 18 variantes de conifères. Le contrôle comptait 76 035 placements végétaux, sous-bois compris.
- L’ancrage prend en compte le côté aval du tronc. Le résultat a été inspecté en vue de gestion et au sol.
- Le laboratoire a chargé un relief assemblé à partir de deux portions du terrain BK. Deux graines testées ont produit des géométries distinctes.
- La fluidité avec cette densité et l’application du kit à la base Unity historique du dépôt restent à vérifier.
