# SkiStation

Projet Unity PC — gestion de station et descente arcade.

**Version actuelle : 3.06, atelier montagne isolé**, basé sur la 3.05 et le ZIP officiel 3.04.

- [Commencer avec la 3.06](COMMENCER_ICI_WORK_3_06.md)
- [Test de l’atelier montagne](TEST_306.md)
- [GPS du domaine 3.05 : protocole de test](TEST_305.md)
- [Provenance et licence FastNoiseLite](THIRD_PARTY_306.md)

Dans Unity : **SkiStation > Montagne > Atelier montagne 3.06**, puis créer une scène d’étude. Cet aperçu s'utilise dans l'onglet Scene, sans Play. La montagne de gestion et le GPS ne sont pas modifiés par cet atelier.

Version Unity indiquée dans le projet : **6000.3.7f1**.

Les contrôles de livraison sont syntaxiques et structurels. La compilation Unity, les tests numériques du générateur et le rendu de la 3.06 restent à valider sur PC. Les sources cumulatives se trouvent directement dans Assets, Packages et ProjectSettings ; les anciennes archives présentes dans le dépôt sont historiques.
