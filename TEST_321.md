# SkiStation 3.21 — Finition géologique 360°

Base directe : 3.20.

## Objectif
Donner au massif une vraie lecture géologique sur absolument toute la map, sans transformer les grandes zones skiables en murs rocheux.

## Ajouts
- barres rocheuses discontinues sur les flancs ouest, est, centre et arrière ;
- ruptures de pente larges à plusieurs étages d'altitude ;
- éperons rocheux isolés sur les côtés et la face arrière ;
- couloirs naturels entre les éperons pour conserver les passages ;
- logique 360° maintenue : aucun versant n'est une façade ;
- glaciers, cols, combes, balcons et vallons précédents conservés.

## Test Unity
SkiStation > Montagne > Atelier montagne 3.21 > Créer une nouvelle scène d’étude.
Tourner autour de tout le massif et vérifier que les rocailles structurent la silhouette sans fermer les grands espaces skiables.

Compilation Unity / Play Mode non exécutés dans cet environnement.
