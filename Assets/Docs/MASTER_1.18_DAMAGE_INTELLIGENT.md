# SkiStation Master 1.18 — Damage intelligent

Le damage devient une véritable planification d'exploitation. Les pistes réelles sont surveillées, classées par priorité et envoyées vers une file de damage. Les seuils critiques passent devant les pistes simplement dégradées. Une seule dameuse active est utilisée par défaut. Le joueur peut désactiver l'automatisme ou utiliser un mode instantané pour éviter toute attente.

Règles : aucune population artificielle ; aucune attente obligatoire ; les opérations chronométrées sont optionnelles.

UI : F5 affiche la file de damage.
