# SkiStation Master 1.52 — Zones fonctionnelles

Les zones physiques créées par le joueur deviennent de véritables espaces fonctionnels.

- **Tapis roulant** : forte capacité d'apprentissage/départ.
- **Téléski débutant** : capacité intermédiaire.
- **Espace d'apprentissage** : bonus de qualité pour les débutants.
- **Espace repos** : bonus de confort.
- **Panneau d'information** : petit bonus de lisibilité.

Contrôle prototype : `Shift + clic` place l'équipement dans la zone sélectionnée. `X` change l'équipement et `C` change le type de zone.

Le système est volontairement léger : pas de réseau d'eau, d'électricité ou de tuyauterie à gérer.
