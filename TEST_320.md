# SkiStation 3.20 — Densification relief 360°

Base directe : 3.19.

## Ajouts
- combes secondaires sur les quatre grands côtés du massif ;
- petits cols de liaison à basse, moyenne et haute altitude ;
- vallons obliques qui ouvrent les flancs ouest et est ;
- traversées naturelles sur la face arrière ;
- contreforts entre les creux pour éviter un relief mou ;
- aucune piste prédessinée : le joueur conserve le choix des tracés ;
- règle absolue : toute la map est pensée et exploitable en 360°.
